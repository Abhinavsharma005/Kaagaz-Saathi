# Gnani AI (Vachana Speech API) Integration Notes

This document specifies the exact REST API endpoints, request schemas, headers, and audio parameters for **Gnani Prisma (STT)** and **Gnani Timbre (TTS)** used in **Kaagaz Saathi**.

---

## 1. Authentication & Base URL

- **Base URL:** `https://api.vachana.ai`
- **Dashboard / API Key Management:** `https://app.gnani.ai`
- **Authentication Header:**
  ```http
  X-API-Key-ID: <GNANI_API_KEY>
  ```
- **Security Rule:** Stored strictly in `backend/.env`. Never exposed in frontend, client bundles, or committed to git.

---

## 2. Speech-to-Text: Gnani Prisma

Gnani Prisma v2.5 provides state-of-the-art transcription for Indian languages and accents, trained on real Indian audio with heavy acoustic variations, background noise, and code-mixing (Hinglish).

### REST Endpoint
- **URL:** `POST https://api.vachana.ai/stt/v3`
- **Content-Type:** `multipart/form-data`
- **Headers:**
  - `X-API-Key-ID: <GNANI_API_KEY>`

### Form Parameters
- `audio_file`: Binary audio content (supported: WAV, MP3, OGG, FLAC, AAC, M4A up to 60 seconds).
- `language_code`: BCP-47 language tag:
  - `hi-IN` (Hindi)
  - `en-IN` (Indian English)

### Expected JSON Response
```json
{
  "success": true,
  "request_id": "019fd17d-1106-7265-88ab-3ed12d029292",
  "transcript": "मेरा नाम राजेश कुमार शर्मा है",
  "model": "gnani-prisma-v2.5"
}
```

## 3. Text-to-Speech: Gnani Timbre

Gnani Timbre v2.5 delivers natural, expressive Indian speech with contextual text normalization (numbers, currencies, dates) and low latency.

### REST Endpoint
- **URL:** `POST https://api.vachana.ai/api/v1/tts/inference`
- **Content-Type:** `application/json`
- **Headers:**
  - `X-API-Key-ID: <GNANI_API_KEY>`

### JSON Request Payload
```json
{
  "text": "कागज़ साथी में आपका स्वागत है। कृपया अपना नाम बताएं।",
  "voice": "Nalini",
  "model": "timbre-v2.5",
  "language": "hi-IN",
  "speed": 1.0,
  "audio_config": {
    "sample_rate": 24000,
    "num_channels": 1,
    "sample_width": 2,
    "encoding": "linear_pcm",
    "container": "wav"
  }
}
```

### Response
- **Status:** `200 OK`
- **Content-Type:** `audio/wav` (binary WAV audio stream)

---

## 4. Credit Conservation Strategy (Frugal Usage)

To ensure the 5,000 Gnani credits are preserved for final demo recording:
1. **TTS Audio Cache:** Audio generated by Timbre is cached in `backend/cache/tts/<md5_hash>.wav`. If the same prompt is requested again, the backend immediately streams the cached file without an API call.
2. **Fixed Question Prompts Pre-Generation:** Standard wizard questions are cached once upon server start.
3. **Mock Mode for Development & CI:** When `DEV_MOCK_GNANI=true` (or when `GNANI_API_KEY` is not set), deterministic mock transcripts and synthetic WAV audio beeps are returned for lightning-fast testing without API costs.
